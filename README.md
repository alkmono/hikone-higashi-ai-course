# AI・データサイエンス講座 案内サイト

彦根東高校の生徒向けの、ビルド不要の静的サイトです。`index.html` が案内のトップ、`qa.html` が公開Q&Aです。GitHub Pagesでそのまま公開できます。

## 1. URL・日時・会場・締切を変更する

`config.js` をテキストエディタで開き、引用符 `"..."` の内側を書き換えます。

- `briefingFormUrl`: 説明会参加登録フォームのURL
- `courseFormUrl`: 講座申し込みフォームのURL
- `questionFormUrl`: 匿名質問フォームのURL
- `qaCsvUrl`: 公開用Q&AスプレッドシートのCSV URL
- `courseSchedule.first`: 第1回の日程
- `courseSchedule.secondAndThird`: 第2・3回の日程
- `briefingDateTime`: 説明会の日時
- `venue`: 会場名
- `applicationDeadline`: 講座の申し込み締切日

文字列の前後にある引用符や、行末のカンマは消さないでください。

## 2. 受付を締め切る

`config.js` の次の値を `true` から `false` に変更します。

```js
briefingRegistrationOpen: false,
courseApplicationOpen: false
```

- `briefingRegistrationOpen`: 説明会の受付状態
- `courseApplicationOpen`: 講座申し込みの受付状態

`false` にした項目はボタンがグレーになり、押せなくなります。補足文も「受付は終了しました」に変わります。再開するときは `true` に戻します。

## 3. Q&A用スプレッドシートを作る

Googleスプレッドシートで、1行目に次の5列をこの順番で作ります。

| A列 | B列 | C列 | D列 | E列 |
| --- | --- | --- | --- | --- |
| 公開 | カテゴリ | 質問 | 回答 | 回答日 |

1. 「公開」列を選び、メニューの「挿入」→「チェックボックス」でチェックボックスにします。
2. カテゴリは「講座の内容」「参加・申し込み」「持ち物・準備」「その他」のいずれかを入力します。それ以外の文字はサイト上で「その他」として表示されます。
3. 回答日は、たとえば `2026/11/1` のように日付として入力します。
4. 「ファイル」→「共有」→「ウェブに公開」を開きます。
5. 公開対象のシートを選び、形式を「カンマ区切りの値（.csv）」にして公開します。
6. 発行されたURLをコピーし、`config.js` の `qaCsvUrl` に貼り付けます。

`qaCsvUrl` が初期状態の仮URL（`EXAMPLE` を含むURL）の間は、動作確認用のサンプルQ&Aが3件表示されます。

## 4. 回答を追加・非表示にする

回答を追加するときは、公開用スプレッドシートに行を追加し、質問・回答・回答日を入力して「公開」にチェックを入れます。質問または回答が空欄の行は表示されません。

回答を一時的に非表示にするときは、その行の「公開」のチェックを外します。再表示するときは再びチェックを入れます。ウェブ公開したCSVへの反映には数分かかることがあります。

> **重要:** Googleフォームの回答が直接保存される回答シートは、個人情報を含む可能性があるため絶対に公開しないでください。サイト用の公開Q&Aは、必ず別のスプレッドシート（別ファイル）に必要な内容だけを転記して作成してください。

## 5. ローカルで確認する

ファイルをダブルクリックして開くのではなく、簡易サーバーを使うと本番に近い状態で確認できます。Pythonが入っている場合、このフォルダでターミナルを開き、次を実行します。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。終了するときはターミナルで `Ctrl + C` を押します。

## 6. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作ります。
2. このフォルダ内の `index.html`、`qa.html`、`style.css`、`config.js`、`main.js`、`qa.js`、`README.md` をリポジトリの最上位にアップロードします。
3. リポジトリの「Settings」→「Pages」を開きます。
4. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
5. Branchを `main`、フォルダを `/ (root)` にして「Save」を押します。
6. 数分待つと表示される公開URLを開きます。

設定を変更したときは、ファイルをGitHubへ再度アップロード（またはcommitしてpush）するとサイトにも反映されます。
